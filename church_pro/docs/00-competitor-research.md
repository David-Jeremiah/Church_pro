# 00 · Competitor Research (October 2026)

Method: public product pages, review sites and vendor articles. Feature lists come from vendors' own marketing, so treat them as claims, not tested facts.

## 1. The market in one paragraph

Western church management systems (ChMS) such as Planning Center, Tithe.ly (which owns Breeze), ChurchTrac, ChMeetings and Pushpay focus on membership, giving, events, volunteer scheduling, child check-in and member portals. A 2026 Pushpay guide groups the market into unified platforms (giving, database and app sharing one data set) and best-of-breed tools. Africa-focused products add what local churches rely on: mobile money, SMS/WhatsApp and low-bandwidth use.

## 3. What the best church accounting tools do

- **Fund accounting.** Money is tracked per fund; restricted funds can only be spent for their purpose. Good tools add user access control, approval workflows and an audit trail.
- **Budgets with real-time tracking** against actual spending, plus forward projections.
- **Expense approval workflows** configured to the church's own governance, with digital approval by budget holders and checks that stop duplicate payments.

## 4. What good procurement looks like (from nonprofit purchasing systems)

1. Purchase request → 2. fund and budget validation → 3. policy check → 4. approval routing → 5. purchase order.
- Budget checks should happen when the request is **submitted**, not when the invoice arrives.
- A "budget block" can stop requests that exceed the available budget.
- Approved requisitions **reserve (pre-encumber)** the money so other requests see the true remaining budget.

## 5. Gaps this product fills

| Gap seen in the church tools reviewed | Our answer |
|---|---|
| Procurement and budget control appear mostly in nonprofit/ERP tools, not in church management systems (including the African ones reviewed) | Built-in requisition → approval → order → receive → pay flow tied to budget lines |
| No remote or hybrid staff tracking found in the church tools reviewed | Office / Home / Field clock-in with team board and monthly summary |
| Churches are usually self-service sign-ups | Platform admin onboards each church and issues the administrator's login, giving you control of the tenant list |
| Accounting assumes a dedicated bookkeeper | Admin **or** accountant can do the books; approval stays with the admin so there is separation of duties when an accountant exists |
| Western tools assume cards | Mobile-money and cash as first-class payment methods (API integration is a later phase) |

## 6. Ideas deliberately postponed

Mobile-money API collection (MTN/Airtel), SMS/WhatsApp bulk messaging, child check-in, volunteer rosters, member self-service portal, payroll, bank reconciliation, multi-branch/parish reporting, sermon and livestream features.
